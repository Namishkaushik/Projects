# Data Science Projects

This repository contains my hands-on data analysis and data science projects.
Each project focuses on applying Python and data analysis techniques to real-world datasets, with clear problem statements and interpretations.

The goal of this repository is to demonstrate my learning journey in data science, including data cleaning, exploratory data analysis (EDA), and insights generation.

**Skills demonstrated:** Data cleaning, EDA, statistical grouping/aggregation, correlation analysis, data visualization, dashboard development

## 📌 Projects

### 1. Student Performance Analysis
**Tools:** Python, Pandas
**Focus:** Exploratory Data Analysis (EDA)

* Analyzed academic, behavioral, and family-related factors affecting student performance.
* Studied the impact of:
   * Study time
   * Absences
   * Alcohol consumption (weekday & weekend)
   * Internet access
   * Parental education
   * Family support
* Used grouping, aggregation, and binning techniques to identify trends.
* Interpreted results with attention to sample size and data limitations.

### 2. Titanic Survival Dashboard
**Tools:** Python, Streamlit, Plotly
**Focus:** Interactive Data Dashboard

* Built an interactive web dashboard to explore survival patterns from the Titanic dataset.
* Included dynamic CSV upload with on-the-fly feature engineering (Family Size, Age Group, Cabin Availability).
* Visualized survival rate across 10 dimensions, including:
   * Gender and passenger class
   * Age distribution and age group
   * Fare vs. survival
   * Family size impact
   * Embarkation port
   * Combined class + gender breakdown
* Deployed locally using Streamlit, with all charts built using Plotly for interactivity.
