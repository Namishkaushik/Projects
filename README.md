## 📌 Projects

### 1. Student Performance Analysis
**Tools:** Python, Pandas  
**Focus:** Exploratory Data Analysis (EDA)

- Analyzed academic, behavioral, and family-related factors affecting student performance.
- Studied the impact of:
  - Study time  
  - Absences  
  - Alcohol consumption (weekday & weekend)  
  - Internet access  
  - Parental education  
  - Family support
- Used grouping, aggregation, and binning techniques to identify trends.
- Interpreted results with attention to sample size and data limitations.
